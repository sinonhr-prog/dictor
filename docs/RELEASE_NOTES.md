# Диктор 0.1.0 — предварительный выпуск

Первая публичная портативная версия для Windows x64. Горячая клавиша Ctrl+Alt+Space, капсула записи, локальное распознавание русской речи, буфер и защищённая проверкой исходного поля команда вставки.

Скачайте **Dictor-Portable-win-x64.zip**, распакуйте весь архив и запустите **Диктор.exe**. Модели и .NET включены. Если Vulkan-профиль не загружается, выберите CPU в настройках и перезапустите приложение. Инструкция — в README репозитория.

В комплекте Whisper large-v3-turbo F16, small Q5_1, Silero VAD и лицензии компонентов. Настройки, записи, транскрипции и SDK разработчика исключены. Для проверки ZIP приложена SHA-256; внутри — checksums.json.

При подготовке прошли 13 тестов, сборка и форматирование, проверка всех 516 файлов ZIP, запуск/выход, загрузка CPU-модели и WPF-рендер. Полная проверка на чистой Windows, с отключённой сетью и в сторонних редакторах ещё не выполнена. Сборка без цифровой подписи. Это предварительный выпуск, а не завершённая приёмка.
